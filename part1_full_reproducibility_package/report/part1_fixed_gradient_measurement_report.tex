\begin{abstract}
This report defines and compares three measurement strategies for the generator-selection step in gradient-based ADAPT-VQE. The fixed method names are \textbf{M1: FC-UG}, fully commuting universal groups for static all-gradient estimation; \textbf{M2: BAI-FC-IG}, best-arm identification using fully commuting individual-gradient measurements; and \textbf{M3: BAI-FC-UG}, best-arm identification using fixed parent fully commuting universal groups. These names must be used consistently in text, code, tables, plots, and file names. The reported numerical values are oracle/noiseless planning diagnostics: exact gradients and exact fragment variances are used to estimate measurement requirements. They are not empirical finite-shot simulations. Part III symmetry filtering and tapering are not included in the Part I numerical tables; Part III supplies a smaller input problem to the same measurement methods.

\textbf{Revision of September 2026.} All numbers in this revision are produced by a single from-geometry implementation in which each method is a separate module that saves the fully commuting groups and the fragment variances behind every table entry. Every run passes a validation gate requiring the Jordan--Wigner Hamiltonian to reproduce the PySCF RHF energy on the Hartree--Fock determinant and the PySCF FCI energy as its lowest eigenvalue in the target particle-number sector. All nine cases are now complete, H$_2$O included, so the three-method comparison no longer has missing entries. Two conclusions of the previous revision do not survive and are corrected in Sec.~\ref{sec:conclusions}. Both free parameters of the previous revision have been removed: M1 is now evaluated at the target radius that matches the winner-identification task, and the BAI methods are evaluated in the schedule-free exact limit rather than on a geometric radius schedule. This revision adds two further pieces. A no-sharing baseline completes the two-by-two the methods span and makes the contribution of each mechanism separately attributable (Sec.~\ref{sec:baseline}). A finite-shot study replaces the exact gradients with estimates from a finite number of shots and runs the same elimination rule on those (Sec.~\ref{sec:finite-shot}); it retracts one conclusion of the earlier revision and shows that the confidence convention is far stricter than the stated failure probability requires.
\end{abstract}

\section{One-sentence problem}

Given a molecular Hamiltonian $H$, a current ADAPT-VQE state $\ket{\psi}$, and a UCCSD generator pool $\{G_i\}$, estimate the measurement cost required to identify a generator with the largest absolute gradient
\begin{equation}
  i^\star = \argmax_i |g_i|,
  \qquad
  g_i = \bra{\psi}\comm{H}{G_i}\ket{\psi} .
  \label{eq:gradient}
\end{equation}
The scientific question is whether using winner-identification statistics and shared fully commuting measurement contexts reduces the gradient-selection measurement cost relative to static all-gradient estimation.

\section{Object lineage}

The qubit Hamiltonian is
\begin{equation}
  H=\sum_p h_p P_p,
\end{equation}
where $P_p$ are Pauli products after Jordan--Wigner mapping. For each generator $G_i$, define the gradient operator
\begin{equation}
  C_i = \comm{H}{G_i} .
\end{equation}
The ADAPT gradient is the expectation value of this operator,
\begin{equation}
  g_i=\expect{C_i}_{\psi}.
\end{equation}
Expanding all gradient operators in one shared Pauli-coordinate system gives
\begin{equation}
  C_i=\sum_{\ell} A_{i\ell}R_{\ell},
  \qquad
  \mu_\ell=\expect{R_\ell}_{\psi},
  \qquad
  \bm g = A\bm\mu .
  \label{eq:gAmu}
\end{equation}
The parent universal Pauli support at this ADAPT step is
\begin{equation}
  \mathcal B_0=\bigcup_i \supp(C_i).
  \label{eq:B0}
\end{equation}
M1 and M3 use $\mathcal B_0$ as a shared measurement object. M2 does not; it groups each $C_i$ separately.

\section{The three algorithms}

\subsection{M1: FC-UG}

M1 estimates the full gradient vector. It forms one global FC grouping of the parent support,
\begin{equation}
  \mathcal B_0 \longrightarrow \mathcal M_1,\ldots,\mathcal M_K,
\end{equation}
where each $\mathcal M_\alpha$ is a fully commuting measurement context. Measurements of these contexts estimate the shared Pauli expectations $\mu_\ell$ and reconstruct every gradient using Eq.~\eqref{eq:gAmu}.

The pilot implementation used deterministic greedy FC grouping of $\mathcal B_0$. This is a Barnes-style global FC all-gradient baseline because it shares contexts across the whole ADAPT gradient pool, but it is not claimed to reproduce every specialized construction in Refs.~\cite{Anastasiou2023ReallyMeasure,Shkolnikov2023Avoiding}.

\subsection{M2: BAI-FC-IG}

M2 changes the statistical target from full-vector estimation to winner identification. Each candidate gradient is an arm in a best-arm-identification problem. Its own commutator support is grouped separately,
\begin{equation}
  \supp(C_i) \longrightarrow \mathcal M_{i,1},\ldots,\mathcal M_{i,K_i} .
\end{equation}
BAI maintains confidence intervals for active gradients and eliminates a generator $i$ if
\begin{equation}
  |\widehat g_i|+r_i < \max_{j\in\mathcal A_r}\left(|\widehat g_j|-r_j\right),
  \label{eq:bai-elim}
\end{equation}
where $\mathcal A_r$ is the active generator set at BAI round $r$ and $r_i$ is the current confidence radius. M2 does not exploit universal cross-gradient sharing.

\textbf{Implementation status.} M2 is now implemented as its own module. Each run writes the individual-gradient FC grouping $\mathcal M_{i,k}$ for every generator, the oracle fragment standard deviation of every fragment, the per-arm shot cost, and the full BAI elimination history with confidence radii and active sets. The M2 column is therefore auditable; it remains an oracle planning diagnostic rather than a finite-shot result.

\subsection{M3: BAI-FC-UG}

M3 combines the mechanisms of M1 and M2. It starts with the same fixed parent universal FC contexts as M1,
\begin{equation}
  \mathcal M_1,\ldots,\mathcal M_K,
\end{equation}
but BAI eliminates generator candidates,
\begin{equation}
  \mathcal A_0 \supset \mathcal A_1 \supset \mathcal A_2 \supset \cdots .
\end{equation}
At BAI round $r$, the active Pauli support is
\begin{equation}
  \mathcal B_r=\bigcup_{i\in\mathcal A_r}\supp(C_i),
  \qquad
  \mathcal B_r\subseteq\mathcal B_0 .
\end{equation}
The active measurement contexts are restricted parent contexts,
\begin{equation}
  \mathcal M_\alpha^{(r)}=\mathcal M_\alpha\cap\mathcal B_r .
\end{equation}
The parent contexts are not rebuilt during BAI. This nested construction keeps previous measurements compatible while allowing the algorithm to stop sampling information that only affects eliminated generators.

\section{Oracle shot proxy}

All Part I numbers are oracle/noiseless planning estimates. The state $\ket{\psi}$ is known exactly in the simulation, so the exact gradient values and exact fragment variances are available. No empirical finite-shot variance learning is included.

For one gradient operator written as a sum of independently measured FC fragments,
\begin{equation}
  C_i = \sum_{\alpha=1}^{K_i} F_{i\alpha},
\end{equation}
with oracle fragment variances
\begin{equation}
  \sigma^2_{i\alpha}=\Var_\psi(F_{i\alpha})
  =\expect{F_{i\alpha}^2}_\psi-\expect{F_{i\alpha}}_\psi^2,
\end{equation}
the optimal independent-fragment allocation gives the approximate total number of shots needed to estimate $g_i$ with one-standard-error target $\epsilon_i$ as
\begin{equation}
  M_i(\epsilon_i)\approx
  \frac{\left(\sum_{\alpha=1}^{K_i}\sigma_{i\alpha}\right)^2}{\epsilon_i^2} .
  \label{eq:single-gradient-shot}
\end{equation}
When a confidence factor is used, $\epsilon_i$ is replaced by $\epsilon_i/z_{\delta_i}$. For BAI diagnostics the tolerance for an arm is determined by the current separation between its estimated absolute gradient and the best surviving absolute gradient. The pilot used a normal confidence model with family-wise failure probability $\delta=0.05$.

For M2 this formula is applied separately inside each gradient arm, because M2 measures each arm in its own contexts. M1 and M3 instead share contexts between generators, so the allocation over contexts is not separable and is obtained by solving the convex programme
\begin{equation}
  \min_{n_\alpha \ge 0} \ \sum_{\alpha} n_\alpha
  \qquad\text{subject to}\qquad
  \Var(\widehat g_i)=\sum_{\alpha}\frac{\sigma_{i\alpha}^{2}}{n_\alpha}\le\epsilon^{2}
  \quad\text{for every active } i ,
  \label{eq:allocation}
\end{equation}
where $n_\alpha$ is the number of shots taken in context $\alpha$. Its stationarity condition is $n_\alpha=\sqrt{\sum_i\lambda_i\sigma_{i\alpha}^{2}}$ for multipliers $\lambda_i\ge0$, which is solved by a damped multiplicative fixed-point iteration and then rescaled so that the tightest constraint holds exactly. The returned allocation is therefore feasible by construction, and for a single gradient it reduces exactly to Eq.~\eqref{eq:single-gradient-shot}. A previous envelope heuristic, which spread shots in proportion to $\max_i\sigma_{i\alpha}$, overestimated the M1 and M3 costs by up to a factor of eight and inverted the M2/M3 comparison; it has been replaced.

The BAI methods are evaluated in the schedule-free limit. As the common confidence radius $r$ decreases continuously, generator $i$ leaves the active set the moment $2r$ falls below its absolute-gradient deficit
\begin{equation}
  \Delta_i=|g_1|-|g_i| ,
\end{equation}
so it is resolved to exactly $\Delta_i/2$; the leader survives to $\mathrm{gap}/2$. Because measurements are reusable, an arm that leaves at radius $r$ has paid the cost of being resolved to $r$ and nothing more, and a shared context has paid the largest requirement it ever saw. The active set changes only at the finitely many distinct values of $\Delta_i$, so the whole trajectory is determined by evaluating the allocation at those radii. For M2 this collapses to the closed form of Eq.~\eqref{eq:m2-exact}. This replaces the geometric radius schedule of the previous revision, whose shrink factor was a free parameter and which, being coarse, overshot the elimination points; Sec.~\ref{sec:sensitivity} quantifies the difference.

Because these formulae depend on the exact grouping and fragment variances, every production run saves the FC groups, the fragment variances and the BAI histories used to generate each table entry.

\section{Benchmark assumptions}

The generator universe is the standard spin-orbital UCCSD pool conserving electron number $N_{\mathrm e}$ and $S_z$, but not generally total spin $S^2$. No frozen-core approximation, no qubit tapering, and no Part II variance-aware coefficient splitting are included in the Part I numerical tables. The CISD state is used as a correlated proxy for a later ADAPT state; it is not a saved ADAPT trajectory snapshot.

FC group counts are routine-dependent. Pre-taper and post-taper counts, or any two rows in the same table, are comparable only if produced by the same deterministic FC grouping routine, with the same Pauli ordering, graph-coloring order, tie-breaking rule, and random seed. Every row in this revision uses one routine: deterministic greedy first-fit grouping, Pauli strings sorted by decreasing weight and then lexicographically, a candidate joining the lowest-numbered group that accepts it, no random seed. The counts therefore differ from the previous revision, whose H$_4$ and H$_2$O rows were produced by a different partitioning routine; those rows were not comparable with the LiH row.

\textbf{Validation gate.} Every case is checked before any gradient is computed: the Jordan--Wigner Hamiltonian must reproduce the PySCF RHF energy on the Hartree--Fock determinant and the PySCF FCI energy as its lowest eigenvalue in the $(N_\alpha,N_\beta)$ sector, both to $10^{-8}$ Ha. Observed errors are at the $10^{-15}$ level. A case that fails the gate aborts rather than producing numbers.

\textbf{Non-zero gradient threshold.} Gradients that vanish by symmetry appear at the $10^{-8}$ numerical noise floor of the integral and SCF pipeline, while the smallest physically non-zero gradient in these cases is of order $10^{-3}$. The counts below use a threshold of $10^{-6}$, which lies on the plateau between the two. The threshold is not innocuous at tighter values: for LiH the count is 26 at $10^{-6}$ and 34 at $10^{-9}$, and every run records the count at $10^{-4}$, $10^{-6}$, $10^{-8}$ and $10^{-9}$ so the choice stays visible.

\subsection{What sets the M1 cost}

M1 must reach its common radius for every generator simultaneously, so its cost is set by the pool member with the largest reconstruction variance $\sum_\alpha\sigma_{i\alpha}^2$. In five of the nine cases that generator has a gradient that is zero to numerical precision, and its variance dwarfs the winner's: for LiH it is \texttt{D 0,1 $\to$ 4,9} with $\sum_\alpha\sigma_{i\alpha}^2=11.76$ against $0.072$ for the actual winner, a factor of 164. In the remaining cases the binding generator carries a small but non-zero gradient, and on H$_4$ side=1.0 with the CISD state it is the winner itself.

This is not a defect of the comparison. M1 is non-adaptive, so it cannot know in advance which generators are irrelevant and must bound every one of them tightly enough to rule it out. Paying for high-variance operators that turn out not to matter is precisely the inefficiency that candidate elimination removes, and it is the mechanism behind the M1/M3 column.

It is also not the whole story. Restricting M1 to the generators with non-zero gradients --- information no non-adaptive method has access to --- reduces its cost by a factor of only $1.6$ to $2.4$ across the nine cases, because the remaining generators also carry substantial variance. The M1 cost is broadly distributed over the pool rather than concentrated in one irrelevant operator; the binding generator sets the constraint, but removing it would not make M1 competitive.

\subsection{Where the cost actually sits: breadth and depth}
\label{sec:breadth-depth}

The shot cost of a BAI method is not concentrated in the final elimination, as a
naive reading of the $1/r^2$ scaling suggests. It splits into two terms of
comparable size, and which one dominates changes with the system.

\emph{Breadth} is the cost of sweeping the whole pool at the coarse radius set by
the largest absolute-gradient deficit, so that the obvious losers can be dropped
at all. \emph{Depth} is the cost of the final tightening that separates the
leader from its nearest rival. For M3 the split is visible directly in the
per-context accounting: a context that only ever served generators which were
later eliminated keeps the shots it was given at the coarse radius, and those
shots are still counted.

\subsection{Why the M3 advantage decays with system size}

Two quantities decide the depth term. The first is the fragmentation penalty
\begin{equation}
  f_i=\left(\frac{\sum_\alpha\sigma_{i\alpha}\ \text{over parent contexts}}
                 {\sum_\alpha\sigma_{i\alpha}\ \text{over its own contexts}}\right)^{2},
\end{equation}
the factor by which the shared grouping makes one gradient more expensive to resolve, which follows from Eq.~\eqref{eq:single-gradient-shot} depending on $\left(\sum_\alpha\sigma_{i\alpha}\right)^2$ rather than $\sum_\alpha\sigma_{i\alpha}^2$. The second is the number of generators still active at the final radius, written $|\mathcal A|$.

LiH, the one case with substantial finalist overlap at 35\%, is also the case where M3 retains a clear advantage despite the largest fragmentation penalty in the set.

\subsection{An alternative: rebuild the grouping once the field narrows}
\label{sec:hybrid}

If the fixed parent contexts are the problem at the depth stage, an obvious remedy is to abandon them once the active set is small and build a fresh fully commuting grouping over only the survivors' union support, accepting that the earlier shots were taken in different circuit settings and do not transfer. This was tested directly. Phase one uses the parent contexts while more than a chosen number of generators remain active; phase two regroups from scratch and is charged the full cost of reaching the final radii, ignoring the head start phase one has already provided, so the totals below are upper bounds.

\section{Finite-shot behaviour}
\label{sec:finite-shot}

Every number above is an oracle planning bound. The elimination rule reads exact
gradients, so it cannot misfire, and the family-wise confidence is asserted rather
than measured. This section replaces the exact gradients with estimates built from
a finite number of shots and runs the same elimination rule on those.

Estimator fluctuations are drawn in the normal limit using the exact fragment
variances, and shots accumulate across rounds rather than being redrawn, so
successive rounds stay correlated as real data would be. Two approximations are
deliberate. The normal limit is assumed rather than tested. And fluctuations are
drawn independently per generator, which is exact for the baseline and for M2,
where every generator has its own shots, but neglects the correlation between
generators read off the same shots in a shared context for M1 and M3. That
correlation affects how errors on different generators co-occur, not the
per-generator rate, because the elimination rule uses individual radii.

\subsection{The one inversion does not survive}

On H$_2$O stretch with the Hartree--Fock reference, the planning bounds give
M2/M3 $=0.86$, the only row in which M3 is more expensive than M2. Under finite
shots the same row gives $1.41$, and M3 wins. The inversion was an artefact of
comparing two bounds that inflate by different amounts, and the conclusion drawn
from it in the previous revision is retracted in Sec.~\ref{sec:conclusions}.

\subsection{The two BAI methods inflate differently}

The inflation is not a common factor. On H$_4$, where the cost is depth-dominated,
both methods inflate by $2.2$ to $3.0$ and the ratio between them is preserved to
within a few per cent. On LiH and H$_2$O, where the cost is breadth-dominated, M2
inflates by $2.8$ to $3.2$ while M3 inflates by only $1.4$ to $1.7$, and the M2/M3
ratio roughly doubles.

The reason follows directly from Sec.~\ref{sec:breadth-depth}. A real run does not
know the deficits $\Delta_i$ in advance, so it discovers them by shrinking a common
radius and overshooting each elimination point. M3's breadth term is a single
coarse sweep of the whole pool, a fixed cost that a schedule cannot overshoot,
whereas every one of M2's per-generator costs is discovered by overshooting. The
more breadth-dominated the system, the less of M3's cost is exposed to the
schedule. Universal contexts therefore help more under finite shots than the
planning bounds suggest, and the advantage grows with system size rather than
shrinking.

\subsection{The confidence model over-delivers by four orders of magnitude}

No trial in any run selected the wrong generator. Sweeping the family-wise failure
probability over nearly its whole range barely changes that.

The reason is structural rather than a defect of the simulation. The procedure
stops when the common radius reaches $\mathrm{gap}/2$, at which point the standard

runner-up is one gap, so in units of the standard deviation of their difference it
is $2z_\delta/\sqrt2=z_\delta\sqrt2$, and the selection-error probability is
approximately
\begin{equation}

  \label{eq:calibration}
\end{equation}
which is $1.6\times10^{-1}$ at $z_\delta=1$, $4.7\times10^{-3}$ at $z_\delta=2$ and

enters only through $z_\delta$, and the stopping radius already supplies most of the
protection. The observed rates match Eq.~\eqref{eq:calibration} rather than $\delta$.

selection-error rate. Inverting Eq.~\eqref{eq:calibration} for a genuine five per

factor of five in the planning bound. Simulation does not bear that out.

\subsection{Good-enough selection}

Stopping as soon as every surviving candidate can be certified within a tolerance
$\Delta$ of the leader, rather than resolving the leader exactly, costs less for
no practical loss. On H$_4$ side=1.0 HF at $\Delta=\mathrm{gap}/4$, M2 falls from
$2{,}007{,}147$ to $1{,}359{,}837$ shots and M3 from $1{,}282{,}967$ to
$893{,}811$, both about thirty per cent, and in every trial the generator returned
was still the exact maximiser.

\section{Parameter sensitivity}
\label{sec:sensitivity}

\subsection{What removing the two free parameters was worth}

The previous revision evaluated M1 at a target radius of $\mathrm{gap}/4$ with no
task-level justification, and evaluated the BAI methods on a geometric schedule
with shrink factor $\gamma=0.5$. Both have been replaced. The M1 target is now
$\mathrm{gap}/2$, the loosest common radius at which a non-adaptive estimate
separates the winner from the field, so that all three methods answer the same
question; this divides the M1 column by four. The BAI methods are evaluated in the
schedule-free limit; a coarse geometric schedule overshoots each elimination point
and overpays.

\section{Within-context correlation}
\label{sec:correlation}

The finite-shot study draws fluctuations independently per generator. That is
exact for the baseline and M2, which give every generator its own shots, but M1
and M3 read several generators off the same shots in a shared context. The
covariance of two generators' fragments inside one context follows from variances
alone,
\begin{equation}
  \Cov(F_{i\alpha},F_{j\alpha})
  =\tfrac12\left[\Var(F_{i\alpha}+F_{j\alpha})-\Var(F_{i\alpha})-\Var(F_{j\alpha})\right],
\end{equation}
and sampling from those matrices makes the simulation exact for the shared methods
as well. It also permits a covariance-aware elimination rule that compares each
pair at the confidence radius of their difference rather than at their individual
radii.

approximation.

\section{Relationship to the previous revision}
\label{sec:previous}

The physics of the previous revision is confirmed. Universal Pauli supports, gradient values, gaps and selected generators are reproduced to six or more digits by an independent implementation. What changed is the cost model, for three reasons.

First, the fully commuting grouping. All rows now use one deterministic greedy routine; the previous revision's H$_4$ and H$_2$O rows used a different partitioning, giving 356 and 9,874 contexts where greedy gives 53 and 2,366. Cost grows with the number of fragments an operator is split across, so this alone is a factor of several.

Second, the previous M1 column was not a single model. For LiH it is reproduced within 8\% by a uniform per-context allocation at one standard error sized to a \emph{typical} rather than worst-case generator (1,929,181 against the reported 2,088,380), which guarantees the target precision for about half the gradient vector rather than all of it. For H$_4$ no combination of grouping, allocation and confidence convention reproduces the reported 182,282,619: uniform allocation at worst-case variance with the previous revision's own 356 contexts lands near $3\times10^7$. That entry also exceeds its own no-sharing baseline of 11,326,894 by a factor of 16, which no valid allocation over shared contexts can do.

Third, the allocation itself. Solving Eq.~\eqref{eq:allocation} rather than spreading shots uniformly is worth about a factor of 17 on LiH; at one standard error the present M1 is \emph{cheaper} than the previously reported value, 1,191,917 against 2,088,380, despite covering the worst case rather than a typical generator. The larger absolute values in Table~\ref{tab:completed} come principally from applying a Bonferroni family-wise $z$ over the pool, a conservative convention applied identically to all three methods and therefore invisible in the ratios.

The consequence is that the previous M1/M2 ratios, which ranged from 0.28 to 627, should not be used. They combine an optimistic LiH entry with an unexplained H$_4$ entry.

\section{Conclusions from the current data}
\label{sec:conclusions}

\begin{enumerate}[leftmargin=2em]
  \item M1, M2, and M3 are defined consistently and implemented as separate modules that save their FC groups, fragment variances and, for the BAI methods, elimination histories. All three are evaluated at one criterion, winner identification at family-wise $\delta=0.05$, with no free schedule or precision parameter in any column.
  \item \textbf{M3 is cheaper than M1 in every case}, by factors of $1.1$ to $192$. The ordering is guaranteed by construction; the content is the size of the factor, which grows with system size.
  \item \textbf{M3 is cheaper than M2 in every case except one, and that one is unresolved.} It wins in eight rows of nine on the planning bounds. The exception, H$_2$O stretch with the Hartree--Fock reference, gives M2/M3 $=0.86$ on the bounds and $1.41$ under finite shots, but Sec.~\ref{sec:routines} shows the same quantity ranges over $0.74$ to $1.30$ across grouping routines. \emph{No verdict should be claimed on that row in either direction}, and the previous revision's conclusion that M3 is not always cheaper than M2 rested on a single arbitrary convention.
  \item \textbf{M2 is not always cheaper than M1.} It wins in seven rows of nine; the counterexamples are both H$_4$ CISD rows, where the gap is wide and static estimation is already cheap.
  \item \textbf{The two mechanisms are substitutes, not complements.} Against the no-sharing baseline the interaction term is below unity in all nine cases, between $0.57$ and $0.96$ (Sec.~\ref{sec:baseline}). Elimination removes the situation that sharing exploits, so applying both buys less than the product of applying each alone.
  \item \textbf{Elimination is the dominant mechanism; sharing contributes little.} On its own, universal grouping is worth $2.2$ to $3.4$ on H$_4$, $1.9$ on LiH, and only $1.1$ to $1.2$ on H$_2$O, while elimination alone is worth between $5$ and $253$. The change of statistical target, not the shared measurement contexts, is what carries the result.
  \item \textbf{Finite shots favour the shared contexts.} M2 and M3 inflate above their planning bounds by different amounts, and the difference tracks breadth-dominance: on H$_4$ both inflate by $2.2$--$3.0$ and the ratio is preserved, while on LiH and H$_2$O, M2 inflates by $2.8$--$3.2$ against M3's $1.4$--$1.7$. M3's breadth term is a fixed coarse sweep that a radius schedule cannot overshoot; every one of M2's per-generator costs is discovered by overshooting. Sharing therefore helps more in practice than the bounds suggest, and increasingly so with system size.
  \item \textbf{The confidence convention does not control the selection-error rate, and the obvious correction overshoots.} No trial in any run selected the wrong generator, and sweeping $\delta$ from $0.05$ to $0.99$ moves the realised rate only to $0.3$--$0.7\%$. But inverting Eq.~\eqref{eq:calibration} for a five per cent target gives ten to twelve per cent in simulation, because that expression ignores generators eliminated wrongly earlier in the run. The cost is not monotone in $z_\delta$ either. An optimum sits near $z_\delta\approx1.8$--$2.1$, worth about $1.7$ in realised cost at two per cent error. Absolute costs should be read in that light; the comparisons between methods are unaffected.
  \item \textbf{Conclusions 1 to 7 are routine-independent on H$_4$ and LiH} (Sec.~\ref{sec:routines}), where ratios move by at most $1.45$ across seven and four groupings respectively and no ordering changes.
  \item \textbf{Modelling within-context correlation is a saving where it is understood, and an open question where it is not} (Sec.~\ref{sec:correlation}). On two of three H$_4$ cases it changes cost by one or two per cent and the covariance-aware elimination rule then halves M3's realised cost at no loss of accuracy. On the third it degrades accuracy sharply for reasons not yet established, so the independent noise model of Sec.~\ref{sec:finite-shot} remains the reported one.
  \item The physics of the previous revision is confirmed; its cost model is not reproducible and its M1/M2 ratios should not be used. See Sec.~\ref{sec:previous}.
  \item All numbers remain single-ADAPT-step diagnostics. Nothing here speaks to the cost of a complete ADAPT trajectory, which is the metric Part III names as primary.
\end{enumerate}

\section{Interface with Parts II and III}

Part II improves M3 by using measured variances and covariances to optimize overlapping universal operators and coefficient splitting. Sec.~\ref{sec:breadth-depth} gives that work a sharper target, but Sec.~\ref{sec:overlap} also raises a caution that should be settled before it is built.

The mechanism Part II proposes for the decisive stage is the pairwise-variance equation of that note: best-arm identification only requires the pairwise differences to be resolved, and
\begin{equation}
  \Var(\widehat g_i-\widehat g_j)=\sum_\alpha\frac{1}{m_\alpha}\Var\!\left(F_{i\alpha}-F_{j\alpha}\right),
\end{equation}
so the covariance that helps enters through co-measurement inside a shared context, not through the two generators sharing Pauli products. That premise was tested on the finalist pair of each system, inside the parent contexts, by comparing the cost of resolving the difference alone against the cost of resolving both generators to the same radius.

Resolving the difference is cheaper only on H$_4$, by a factor of $1.11$; on LiH and both H$_2$O rows it is more expensive, by factors up to $1.7$. The arithmetic is unforgiving. Resolving two generators separately costs $\sigma_i^2+\sigma_j^2$ in units of $\epsilon^{-2}$, while resolving one difference observable costs $\sigma_{i-j}^2$, so the difference wins only when $\sigma_{i-j}<\sqrt{\sigma_i^2+\sigma_j^2}$, which for comparable arms demands roughly $30\%$ cancellation. The measured cancellation, $1-\sigma_{i-j}/(\sigma_i+\sigma_j)$, is $33\%$ on H$_4$ but only $17\%$ on LiH and $7\%$ on H$_2$O stretch, consistent with the finalist support overlaps in Table~\ref{tab:overlap}.

This does not refute Part II, whose other mechanisms --- coefficient splitting over an overlapping cover, empirically estimated context covariances, and adaptive choice of the next context to measure --- are untouched by this test. It does mean the pairwise-difference mechanism should not be assumed to pay, and that whether cancellation is available must be measured on the intended benchmark before the variance-aware machinery is designed around it. Sec.~\ref{sec:breadth-depth} adds a second caution: that mechanism acts on the depth term, which is only $12\%$ of the M3 cost on LiH and about $39\%$ on H$_2$O stretch, so its total effect is bounded even where it does pay.

Part III changes the ADAPT trajectory so that the commutators first become symmetry-filtered and tapered. When Part III is active, the Part I object $C_i$ is replaced by
\begin{equation}
  C_{i,\mathrm{tap}}^{\parallel,k}
  =\mathrm{Taper}_{\mathcal R_k}\left(\Pi_{\mathcal R_k}([H,G_i])\right),
\end{equation}
and then M1, M2, or M3 is applied to these reduced operators. Part I tables do not include this reduction.

Two implementation defects of the previous revision are worth recording, because both were silent. The two-electron integrals were inserted into the spin-orbital tensor in chemist rather than physicist ordering, with the spin pattern $(a,b,a,b)$ instead of $(a,b,b,a)$ and without the one-half prefactor; and the computational basis was indexed little-endian where the sparse-operator convention is big-endian. For H$_4$ the resulting Hartree--Fock energy was $-5.21$ Ha against an RHF value of $-1.76$ Ha. The validation gate described in Sec.~6 exists to make a repeat of this impossible.

\section{Remaining work in Part I}
\label{sec:remaining}

\begin{enumerate}[leftmargin=2em]
  \item \textbf{Explain the H$_4$ side=2.0 correlation anomaly} (Sec.~\ref{sec:correlation}). Correct joint noise degrades selection accuracy on that one case, the leading explanation is refuted by measurement, and the covariance-aware rule does not recover it. Until this is understood the correlated noise model cannot be used for reported numbers, and the finite-shot figures keep an approximation that is exact only for the baseline and M2.
  \item \textbf{Extend the routine sweep to the remaining H$_2$O rows.} One row has been swept and it dissolved a conclusion. The other three, and the individual groupings that M2 and the baseline depend on, have not.
  \item \textbf{Adopt a confidence convention.} The evidence points to $z_\delta\approx1.8$ to $2.1$. Choosing it changes every absolute number and the tables should be regenerated once it is fixed.
  \item \textbf{Make good-enough selection the default stopping rule} rather than a diagnostic, given that it costs thirty per cent less with no observed loss.
  \item \textbf{Version control.} The raw commutator expansions are now saved with each run; the code still needs a repository so that a commit hash can accompany every table.
\end{enumerate}
